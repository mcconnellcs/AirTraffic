Desk radar · ESP32-4848S040

Install AirTraffic

Put the radar on your board straight from this page. No apps, no code, nothing to download. It takes about five minutes.

  1. Plug in the board

    Connect it to the Mac with a USB-C cable. Use a cable you know moves data, such as one that syncs a phone. Many cheap cables only carry power, and the board will never show up with one of those.

    Use Google Chrome or Microsoft Edge. Safari cannot talk to USB devices.

    Close the Arduino IDE if it is open, because it can hold on to the board.

  2. Optional: test the screen

    BoardTest shows red, green, blue and white bars, then a spinning line. Touch the glass and an orange dot follows your finger. If this works, the board and cable are good.

    This browser can't install. Open this page in Google Chrome or Microsoft Edge on a computer. Not allowed here. This page must be opened over https.

  3. Install the radar

    Click the button, choose the port that looks like usbserial or USB Serial, then Connect and Install. Keep the cable in until it says done (two or three minutes).

    This browser can't install. Open this page in Google Chrome or Microsoft Edge on a computer. Not allowed here. This page must be opened over https.

    Installs the latest release.

  4. Set up Wi-Fi from your phone

    Unplug the board and plug it back in. It shows a QR code. Scan it, or join the AirTraffic-Setup Wi-Fi network, pick your home 2.4 GHz network and type its password. The radar appears within a minute. Full first-boot guide.

It didn't work
  • No port in the list: try a different cable first, then a different USB port. Plug straight into the Mac, not through a hub.
  • "Failed to connect" or it stalls at the start: unplug the board, wait two seconds, plug it back in and click Install straight away. You don't need the buttons inside the case; the installer presses them for you electronically.
  • "Port is busy": quit the Arduino IDE and any other program using the board, then try again.
  • Screen stays dark after installing: unplug the board, wait two seconds and plug it back in.
  • More help: troubleshooting guide.

Installing replaces whatever is on the board and clears its saved Wi-Fi, so you'll set Wi-Fi up again afterwards. Want to change the code and build it yourself? Follow the Arduino IDE guide.
